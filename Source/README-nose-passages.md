# Original Probe Core and nose pressure passages

`build_nose_passages.py` uses Python 3's standard library to generate independent
parametric pressure skins; it does not import or redistribute any Mk-33 art.
The actual PART/INTERNAL/hatch bindings are generated by `generate_patch.py`.

```sh
python build_nose_passages.py
python verify_nose_passages.py
```

The verifier requires NumPy, SciPy and the bundled GPL `.mu` reader. It decodes
the final binary collision meshes, verifies topology, inward winding, no end caps,
actual material/UV references, and selected body/helmet capsule centre paths in
both directions. It does not execute KSP, native hatch links, ModuleManager,
source MeshCutter operations, gravity or PhysX cooking.

Probe Core coordinates in its own Unity IVA space:

- Rear port: `(0, -0.625, 1.5852)`, matching `bottom` and the cockpit front exit.
- Front port: `(-0.0059150452726, -0.76936990023, -1.37194791559)`, matching `topNode`.
- Bore vertex radius: `0.515 m`, 32 sides, no terminal caps.
- Solid shell: `Mk33ProbeCoreShell`; three IVA-only lights and visual fixtures.

The separately attached Mk33DockingNoseCone owns its real ModuleDockingNode.
Its own pressure skin spans `(0,0,0)` to `(0,0,-0.245)` in nose IVA space.
The native docking plane is approximately `(0,0,-0.259950012)`.
`Mk33NoseDockTube` starts at the outward end, has unit negative-Y geometry,
and rotates by positive 90 degrees around X, making native tube scaling extend
outward along negative IVA Z. Its collider and rendered skin share that node.
The static shell is `Mk33NoseDockShell`; it has one IVA-only light.

Do not attach ProbeCore's docking hatch directly to a nonexistent docking node:
ProbeCore is the transfer corridor; the separate nosecone owns docking binding.
All open interfaces need the runtime pressure hatches configured in the patch.
