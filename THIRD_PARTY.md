This is an independent compatibility patch, not an official release of either
Mk-33 or FreeIVA. Upstream ownership and trademarks remain with their authors.

Version 0.2.0 adds independently drawn 512px panel, tread, hatch and wayfinding
maps, geometric luminaires and native point lights. These are original MIT
assets, generated by build_materials.py/build_corridors.py/build_hatches.py.
No installed IVA props or fonts are copied. The window mask reads installed
window geometry only at runtime; none of its original triangles is bundled.

Version 0.3.0 adds independent parametric dogleg, Probe Core and nose passage
skins and code-generated pressure doors. Original external/IVA assets were
read for alignment/clearance only and are not embedded in the delivered art.
The behavior test harness includes locally authored dependency doubles only;
these are test fixtures and are not shipped as runtime assemblies.

Version 0.3.1 adds original fitted lamp housings, diffuser textures and wall-mounted
ladder supports. All are authored parametrically; no outside image assets are copied.

Version 0.3.3 includes an independent Python port of the relevant sequential
KSPCommunityFixes 1.41.1 .mu-reader behavior in `Source/verify_kspcf_mu.py`.

`KSPCommunityFixes/Library/MuParser.cs`.

See `LICENSES/MIT-KSPCommunityFixes.txt`. The regression port is distributed
under GPL-2.0-or-later with the upstream MIT attribution retained. It exercises
the supported serialized component subset; it is not a Unity/KSP runtime.

Version 0.3.5 reads only the installed FreeIVA
`FreeIva/Props/FreeIva_Hatch_Round_Size1` leaf/handle meshes and materials at
runtime. It does not redistribute them or copy their physics, animation, tube,
frame or cutout. The lower cockpit EXIT handle is selected from the installed
original Dashboard mesh at runtime; original source triangle data is not embedded.

The new corridor wall, floor and ceiling diffuse images were generated for this
patch using image_gen.imagegen. Original Mk-33 artwork was not supplied to image
generation or embedded in the new maps. The PNGs are canonical image sources;
see Source/material_sources.json for provenance and checksums. The legacy MIT
asset notice applies to our authored package assets to the extent rights exist.
