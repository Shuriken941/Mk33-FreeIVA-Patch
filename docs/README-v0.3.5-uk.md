# Mk33FreeIVA 0.3.5

Патч для Mk-33 1.3.3.0, KSP 1.12.5 і FreeIVA 0.2.20.2.
Архів містить готову DLL, власні коридори, текстури та джерельний код.

## Установлення

1. Повністю закрийте KSP.
2. Збережіть резервну копію й видаліть стару папку `GameData/Mk33FreeIVA`.
3. Скопіюйте нову `GameData/Mk33FreeIVA` з архіву до своєї `GameData`.
4. Залиште встановленими Mk-33, FreeIVA та ModuleManager.
5. Запустіть гру заново: quickload не оновлює ресурси IVA.

Оригінальні файли Mk-33 та FreeIVA не замінюються. Для Control Cab потрібен
Breaking Ground (Serenity). Додаткові набори IVA-пропів не потрібні.

## Зміни 0.3.5

Вікна отримали окремий прохід запису глибини на основі встановленої геометрії
скла. Він приховує IVA за вікнами, не зафарбовуючи зовнішній світ. Матеріал,
прив’язка до FreeIVA та стан маски перевіряються після завантаження й під час
перемикання камери. Початкове скло й фізичні оболонки збережені.

Коридори отримали нові синьо-сірі м’які панелі з ромбічною прострочкою,
темну ребристу підлогу та світлі стельові панелі у стилі Mk-33. Лампи й опори
драбини залишаються прикріпленими до своїх поверхонь. Траси та колізії проходів
не змінено.

Круглі люки використовують деталізоване полотно штатного круглого люка FreeIVA.
Модель і матеріали беруться зі встановленої FreeIVA під час завантаження.
При відкритті полотно зникає разом із фізичною перегородкою; ручки для повторного
закриття залишаються доступними. Анімацію відкриття не додано. Якщо ресурс
відсутній, залишається попереднє непрозоре полотно з фізичною перегородкою.

Великі двері **EXIT / UNLOCK / EMERGENCY SLIDE** на нижній палубі Cockpit
тепер мають дію EVA через ручку **UNLOCK**. Підійдіть до неї та скористайтеся
стандартною взаємодією FreeIVA з люком. Вона одразу виконує штатний вихід EVA
через бічний вихід кабіни; герметичне полотно залишається на місці.
Штатні обмеження EVA та перевірка перешкод зберігаються.

## Збережені маршрути

- Центральний **AIRLOCK** Krew Module автоматично відкривається після висування
  труби й стикування із сумісним FreeIVA-портом. Після втрати стику закривається.
- Верхній сусідній люк Krew Module виконує EVA; він не веде до труби.
- Проходи через External Airlock, Cockpit, Krew Module та MidTank збережені.
- Передній нижній люк Cockpit веде через Probe Core до окремого носового порта.

Штатний **Mk-33 Probe Core** не містить стикувального вузла. Потрібен окремий
**Mk-33 Shielded Docking Port** (`Mk33DockingNoseCone`), установлений на ньому.
Вибирайте саме порт, висуньте механізм і задайте його точку керування.
Звичайний Mk-33 Nose Cone — обтічник. Початкові модулі порта та їхні індекси
анімації патч не змінює. Інший апарат також має підтримувати FreeIVA.

Прохід через MidTank розрахований на перший Mission Module slot і штатні
позиції деталей без Offset/TweakScale.

## Перевірка

Збірка перевіряється компіляцією проти фактичних API KSP/Unity/FreeIVA,
тестами коду із замінами залежностей, читанням моделей та числовими перевірками
геометрії. Колізії й налаштування робочих маршрутів порівняні з 0.3.4.

**KSP, графічний рушій Unity та PhysX тут не запускалися.** Перевірку вигляду
вікон у грі, EVA та проходження після стикування потрібно виконати у вашій збірці.
Докладний порядок — `Tests/instructions.md`; межі тестів — `Tests/VALIDATION.md`.

Патч не містить чужих DLL, оригінальних моделей чи текстур Mk-33/FreeIVA.
Атрибуція та ліцензії — `THIRD_PARTY.md` і `LICENSES`.
